# 投稿必填資訊檢查清單
版本：2026-07-04

## 通用必填（所有平台）

- [ ] 筆名（平台唯一，一旦註冊不可改）
- [ ] 作品標題（中文 / 英文）
- [ ] 一句話简介（≤15 字，用於縮圖 / 列表頁）
- [ ] 完整作品简介（100–500 字）
- [ ] 類型標籤（必須符合平台分類樹）
- [ ] 關鍵字 / 標籤（3–10 個，逗號分隔）
- [ ] 章數（已寫完 *且* 校對完成）
- [ ] 每章字數（>1,000 字 / chapter）
- [ ] 封面圖（尺寸、格式、免版權來源）
- [ ] AI 創作披露聲明（如平台要求）
- [ ] 內容警告（ violent / sexual / mature 等）
- [ ] 稿件語言 = 平台主語言

## 平台-specific

| 平台 | 額外欄位 |
|------|----------|
| Royal Road | Genre tags（LitRPG / Progression / Fantasy…）、Author Notes 風格、Premium 意願 |
| 晋江文学城 | 类型（纯爱 / 言情 / 玄幻…）、是否签约、公告欄披露文、笔名、Volume 字数預估 |
| Wattpad | Cover（640×1000px 建議）、Reading list placement、Age rating（13+ / 18+） |

## 上傳前 checklist

- [ ] 全文搜尋「尚無正文」「TODO」「章節待寫」→ 必須 0 結果
- [ ] 字數審計通過（所有章節 >1,000）
- [ ] 語言一致性（繁中→簡中平台不能直接貼）
- [ ] 格式純淨（無多餘 markdown、無 debug 字串、無 Unicode 控制字元）
- [ ] 投稿框格式確認（一次貼 / 分章貼）
- [ ] 備份為壓縮包（.zip 或 .7z）
